# Enhancing Solar Photovoltaic Energy Using an AI-Powered Monitoring System

## Project Overview
This project explores AI and machine learning techniques for predicting solar photovoltaic power output using environmental and operational parameters.

## Machine Learning Models
- Ridge Regression
- Gradient Boosting Regressor

## Input Features
- Solar irradiance (G)
- Solar cell temperature (T_cell)
- Empirical power estimate (P_emp)
- Hour
- Day of year

## Evaluation Metric
Mean Absolute Error (MAE)

| Model | MAE |
|---|---:|
| Ridge Regression | 6.8128 |
| Gradient Boosting Regressor | 6.8440 |

## Technologies Used
Python, Pandas, Scikit-learn, Joblib

## Purpose
To study the potential of machine learning for improving photovoltaic power prediction and supporting solar energy monitoring.
